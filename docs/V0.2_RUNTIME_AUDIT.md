## Known bugs found & fixed during v0.2

1. Logger `(?i)` inline-flag regex crashed every log line (Dart RegExp is
   ECMAScript) — surfaced when the first real process start failed; patterns
   are precompiled and flag-free now. Redaction covered by tests.
2. LatencyTester double-listened the socket stream (single-subscription) —
   replaced with a single-pump `_SockReader`; the live-tunnel probe test
   exercises the fixed path.
3. Generated sing-box configs used the removed `dns`/`block` outbounds and
   missed `route.default_domain_resolver` — rejected by real sing-box 1.14;
   the generator now emits engine-1.14-valid configs (kept 1.11–1.13 legacy
   DNS shapes only where the version check allows).
