## Bugs found by live validation → fixed (with regression tests)

1. **HTTPS probe was plaintext over the TLS port** — every real node failed
   `HTTP_FAIL (http)`. Rewrote `testHttpViaSocksProxy` on `RawSocket`+
   `RawSecureSocket` with TLS upgrade after CONNECT (verification ON).
2. **`RawSocket` null-read deadlock** — read events must be re-enabled after
   a null read; previously probes hung/timed out.
3. **Partial `RawSocket.write` corruption** — write loop hardened.
4. **Loopback destinations routed through proxy nodes** — added
   `ip_is_private → direct` rule (mock-destination E2Es caught it).
5. **Subscription sniffer rejected real URI lists** (comment lines) —
   `every` → `any`.
6. **ParseError echoed node credentials** — raw payload never emitted now
   (shape only).
7. **SS-server fixture lacked domain resolver** — sing-box 1.12+ requirement;
   TLS-through-tunnel probes were terminated.
8. **Traffic counters null on first read** — seeded at start.
9. **MDVPN readiness timeout (6 s) < tunnel negotiation (~10–30 s)** — 60 s.
10. **tasklist PID substring false positives** — CSV column-exact match.
